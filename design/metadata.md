# KODI nfo format
I use a superset of KODI's metadata for movies and shows. Here's their nfo format for music

## album.nfo
```
<album>
    <title>Album Title</title>
    <artist>Artist Name</artist>
    <year>2026</year>
    <genre>Electronic</genre>
    <review>Review text here</review>
    <musicbrainzalbumid>uuid-string</musicbrainzalbumid>
</album>
```

## artist.nfo
```
<artist>
    <name>Artist Name</name>
    <sortname>Name, Artist</sortname>
    <biography>Full biography of the artist.</biography>
    <genre>Rock</genre>
    <genre>Electronic</genre>
    <musicbrainzartistid>uuid-string</musicbrainzartistid>
</artist>
```
